# 🐍 Python Mini Projects Collection

Welcome to my personal repository of **fun and educational Python mini-projects**! 🎉  
This repo showcases beginner to intermediate-level Python programs that are interactive, engaging, and perfect for learning by doing.

> 🔧 **Technologies Used:** Python 3 • Standard Libraries  
> 🧠 **Focus Areas:** Logic Building • Games • Randomization • User Interaction

---

## 📦 Projects Included

### 🎯 1. Perfect Number Guessing Game
**File:** `perfect_guess.py`  
Try to guess the number chosen by the computer in the fewest attempts possible!  
🧠 This project helps you understand:
- Random number generation
- User input handling
- Conditional loops and logic

➡️ *Features simple hints like "Too High" or "Too Low" to guide the player.*

---

### 🔐 2. Password Generator
**File:** `pswd_gen.py`  
Generate **strong, secure passwords** based on user preferences!  
💡 Customize:
- Length of the password
- Use of uppercase letters, digits, and special characters

📚 Learn:
- String manipulation
- Character libraries (like `string` and `random`)
- Input handling

---

### 🐍💧🔫 3. Snake Water Gun Game
**File:** `s_w_g_game.py`  
A twist on the classic **Rock-Paper-Scissors** game using Snake 🐍, Water 💧, and Gun 🔫.  
👨‍💻 You play against the computer in a 10-round battle!

🕹️ Concepts:
- Randomized choices
- Game rules logic
- Scorekeeping

---

### 🎰 4. Slot Machine Simulation
**File:** `slot_machine.py`  
Try your luck at a virtual **slot machine** game! 🎲  
💰 Start with a virtual balance, place bets, and spin the machine to match symbols.

🎯 Practice:
- Lists and loops
- Random symbol generation
- Win/lose calculations
